# QA: международный прайс и запрос пациента

Дата проверки: 18 сентября 2026 года. Проверены текущий код, исходный файл `ПРЕЙСКУРАНТ с 24.08.xlsx`, каталог JSON и локальная копия базы. Продакшен не изменялся.

## Решение о выпуске

**Технические сценарии пройдены; публикацию тарифов следует удержать до подтверждения финансовым владельцем.** В исходном файле есть одинаково названные услуги с разными ценами, а выбор колонки G как тарифа для всех международных пациентов пока не подтверждён. Файл также не содержит заполненного утверждения/номера приказа. Эти вопросы нельзя безопасно исправить программным предположением.

После подтверждения тарифов нужна резервная копия продакшен базы. С обновлением от 18.09.2026 каталог импортируется автоматически при следующем запуске продакшен Strapi; ручные команды и проверка `npm run import:prices:dry` описаны в [инструкции импорта](PRICE_CATALOG_IMPORT.md). Повторный запуск не должен переписывать изменения сотрудников.

## Исправленные дефекты

1. **Высокий приоритет:** публичный запрос с `fields[]=price&fields[]=currency` мог прочитать неактивную запись. Проверка активности теперь использует необходимые поля независимо от проекции ответа.
2. **Средний:** пациент мог получить `managerNote` через API своего запроса. Поле исключено из ответов пациенту.
3. **Средний:** изменение только названия старой KZT записи могло оставить числовую цену без пересчёта и пометить её как USD. Теперь при такой правке используется исходная KZT сумма и официальный курс; производные поля нельзя подменить через API.
4. **Средний:** сохранение после смены курса могло дать USD сумму, отличающуюся от показанного сотруднику превью. Форма передаёт курс и дату; сервер отклоняет устаревшее превью кодом 409.
5. **Низкий:** черновик через публичный `findOne` давал 500 вместо 404; ошибки валидации цены выдавались как сбой сервиса курсов; поиск не находил `D-димер` при пробелах вокруг дефиса; фильтр показывал категории из других разделов. Все четыре случая исправлены и повторно проверены.

## Блокеры данных перед публикацией

**P0 — подтверждение тарифной колонки.** Сейчас используется G («дальнее зарубежье»). Для пациентов из СНГ в файле есть отдельная колонка F. Владелец прайса должен письменно подтвердить, что единый международный каталог использует G, либо дать правило выбора тарифа по стране.

## Остаточные риски и улучшения

- **P1, содержание:** исходник содержит только русские медицинские названия. Переведены элементы интерфейса и категории, но пациент на английском или казахском увидит русские названия 1 882 услуг. Нужен согласованный медицинский перевод.
- **P1, клиническая классификация:** 11 лабораторных скрининговых пакетов (лист «Платный», строки 1133 и 1168–1177) отнесены к check-up. Клинический владелец должен подтвердить, удобно ли это пациенту.
- **P2, уведомления:** если выборка менеджеров завершится ошибкой после сохранения запроса, API может ответить ошибкой, хотя запрос уже создан; повторная отправка создаст дубль. Требуется отдельная идемпотентность/очередь уведомлений.
- **P2, масштаб:** каталог загружает до 10 000 опубликованных позиций в память и фильтрует их там. При текущих 1 883 позициях локальная задержка приемлема; перед ростом сверх лимита нужна фильтрация и пагинация в БД, а также нагрузочный тест на окружении, похожем на продакшен.
- **P2, локальные данные:** один ранее существовавший активный элемент называется `test` и отображается пациенту за $24,98. Перед выпуском владелец данных должен проверить и отключить его, если это тестовая запись.
- **P3, локализация формы:** подписи KZT и курса в форме сотрудника частично на русском. Это не меняет сумму, но мешает англоязычному сотруднику.

## Границы проверки

Тесты выполнены на локальном Strapi + SQLite и локальном Vite через Chrome. Не проводились испытание реального платёжного провайдера, нагрузочный тест продакшена, проверка исходного прайса финансовым владельцем и медицинская экспертиза названий. Курс [НБК](https://nationalbank.kz/ru/page/RSS) является ежедневным официальным курсом, а не внутридневной котировкой.
